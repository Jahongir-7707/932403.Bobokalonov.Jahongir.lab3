## Цель

Освоить Flexbox для одномерных макетов, CSS Grid для двумерных и принципы адаптивной вёрстки.

## Flexbox

- **Меню** (`.nav-list`): `display: flex`, `flex-wrap: wrap`, `justify-content: center`. При нехватке ширины пункты переносятся на вторую строку, горизонтальной прокрутки не появляется.
- **Карточки «Гаджеты недели»** (`.cards` / `.card`): контейнер `display: flex; flex-wrap: wrap; gap`, карточка `flex: 0 1 calc((100% - 3 * var(--gap)) / 4)`. Внутри карточки вторая ось: `flex-direction: column`, текстовый блок `flex-grow: 1`, поэтому низ карточек выравнивается независимо от длины названия.
- Семантика карточки: `<article>` + `<img alt>` + `<h3>` + `<p>` с ключевой фишкой устройства.

## CSS Grid

Дашборд «Сравнение характеристик» (`.dashboard`): `grid-template-columns: repeat(3, minmax(0, 1fr))`, 6 плиток — три параметра (процессор, экран, батарея) для двух устройств, то есть 3 колонки на 2 строки. `minmax(0, 1fr)` не даёт колонке раздуться шире контейнера.

Числовые значения размечены тегом `<data value="...">`: в тексте число в привычном виде (`3,39`), в атрибуте — машиночитаемое значение (`3.39`).

## Адаптивность

| Ширина | Карточки | Дашборд | Остальное |
| --- | --- | --- | --- |
| > 900px | 4 в ряд | 3 колонки | боковая панель справа, `sticky` |
| 601–900px | 2 в ряд | 2 колонки | боковая панель уходит под контент |
| ≤ 600px | 1 в ряд | 1 колонка | навыки в одну колонку, уменьшены шрифты |

Проверено в DevTools на ширинах 1280, 820, 390 и 320 px: `document.scrollWidth` равен ширине окна, горизонтальной прокрутки нет. За это отвечают `minmax(0, 1fr)` в сетках, `min-width: 0` у контента, `max-width: 100%` у изображений и `flex-wrap` в меню.

## Доступность

- Контраст основного текста `#eceef1` на `#000000` — 18:1, второстепенного `#b0b5bc` на `#17181b` — 8,6:1, текста на металлических пластинах `#2c2f33` — от 4,7:1. Минимум по требованию 4,5:1 соблюдён везде.
- У всех изображений заполнен `alt`, у полей формы — `<label for>`.
- Заголовки идут по уровням: `h1` → `h2` в секциях → `h3` в карточках.
- Состояния `:focus` видны: свечение у кнопок, подсветка рамки у полей.
